How it works

From job description to PDF in one pass

The AI writes the content. Plain code does the formatting and the checking, so the layout never drifts and the text stays readable by ATS software.

What gets installed

Five small tools. Nothing runs in the background.

The setup command checks each one and asks before installing anything.

🟢
You install, once

Node.js

Runs the builder and the checker. Any version 22.13 or newer.

📦
npm run setup

Two npm packages

docx builds the Word file and pdf-lib checks the PDF page count.

📄
npm run setup (asks first)

LibreOffice

Free office suite. Turns the Word file into a PDF with real, selectable text.

🤖
You install, one command

An AI agent

Claude Code is the tested choice. Any coding agent that can run commands works.

🔤
Windows has it

Calibri or Carlito

Keeps the layout exact. On Linux, setup installs the free look-alike (Carlito).

🔍
Optional

poppler

Adds one more check that the PDF text is readable. Safe to skip.

Where things live

One master resume. A fresh PDF for every job.

Keep your old resume (PDF or Word) in resume/source/. The agent reads it once and turns it into your master. After that, every job gets its own working copy and its own PDF.

tailorcv/
├─ resume/
│  ├─ source/            ← drop your old resume PDF here
│  └─ base_resume.json   ← YOUR master resume
├─ work/                 ← temporary files per job
├─ output/
│  └─ Acme/
│     └─ your_name_resume.pdf   ← send this one
├─ CLAUDE.md             ← the agent's instructions
├─ LESSONS.md            ← what the agent learned
├─ config.json           ← output folder, page limit
├─ kit/                  builder + checker (don't edit)
└─ scripts/setup.js      installer (don't edit)

Quick start

Eight steps, about half an hour the first time

Pick your system once. Every command below has a copy button.

Install Node.js

Download the LTS version from nodejs.org, or use a command. Then open a new terminal (Windows: PowerShell).

winget install OpenJS.NodeJS.LTS
brew install node

Use the installer from nodejs.org (Linux package managers often ship an old version).

node -v

Download the project

With git, or use the green Code button on GitHub and choose Download ZIP.

git clone https://github.com/niteshjainy/tailorcv.git cd tailorcv

Run the setup

It checks Node, the packages, LibreOffice and the font, and asks before installing anything. Say y.

npm run setup

Test the PDF

You should see pages: 2 and text OK. Open the PDF to compare it with the preview above.

npm run example

Install and log in to the AI agent

Claude Code is the tested choice (needs a paid Claude plan or an API account). Close and reopen the terminal, go to the project folder, run claude, and log in in the browser.

irm https://claude.ai/install.ps1 | iex
curl -fsSL https://claude.ai/install.sh | bash
claude

Another agent? Start it in this folder and say: Read AGENTS.md and follow it exactly.

Add your resume (one time)

Copy your old resume file into resume/source/, then paste this to the agent. You can also paste your resume text instead of a file.

Read CLAUDE.md, LESSONS.md and kit/FORMAT_SPEC.md. Run "npm run doctor". My base resume is still the sample, so start onboarding. My resume is the file in resume/source/. If you cannot read it, I will paste the text.

Check the result carefully: job titles, company names, dates, education and certifications must be exactly right because they are locked from now on.

Make your first tailored resume

Replace the company name and paste the whole job description.

Company: Acme JD: <paste the complete job description here>

Your PDF appears in output/Acme/.

Review, then apply

Read the PDF. Delete anything you could not explain in an interview and replace estimated numbers with your real ones. Just tell the agent, for example:

The page-load improvement was 22 percent. Update it and rebuild.
Every new job after that is three steps: open a terminal in the project folder, run claude, send Company: … and the JD. Need a cover letter, a short "why this role" answer, an application email or a list of skills for a form? Just ask the agent.
Safety rails

What the tool will and will not do

The agent writes. The code enforces the rules.

🔒
Facts are lockedChanging a company, date, degree or certification stops the build.
🧱
No hand-drawn PDFsOnly the Word-to-LibreOffice route is allowed, so text always stays readable.
🧪
Built-in checksUnique verbs, numbers in bullets, banned buzzwords, skills that match the text.
🚫
No leaked company namesProduct and initiative names from the job post are caught before they reach your resume.
🔢
Estimates are flaggedAny number that is not from your master resume is called out so you can replace it.
🧠
It learnsTell the agent what was wrong. It writes a lesson and adds a check so it does not repeat it.
You are responsible for what your resume says. The agent mirrors each job description on purpose and adds the skills it asks for. Read every PDF and remove anything that is not true for you.
Questions

FAQ

Is it free?

The project is free and open source (MIT). The AI agent is separate: Claude Code needs a paid Claude plan or an API account. You can also use the project without any agent by editing the JSON yourself (manual mode).

Where does my resume go?

The project never uploads anything. Your resume and the job description are sent only to the AI provider you connect. Keep your real resume/base_resume.json out of any public repository.

Does it work on Windows?

Yes. Windows, macOS and Linux are supported. On Windows, setup can install LibreOffice with winget.

Can I use ChatGPT or another model?

Any coding agent that can read files and run terminal commands works. A plain chat window cannot run the build, but you can paste the rewritten JSON into the project and build it yourself.

Why a Word file and LibreOffice?

PDFs drawn straight from code often have broken letters, overlapping lines and wrong fonts, which ATS software cannot read. Converting a real Word file gives clean text and correct wrapping.

Can I change the look, page size or output folder?

Yes. Output folder, file names and the page limit are in config.json. A4 paper and other tweaks are explained in docs/05-TROUBLESHOOTING-AND-CUSTOMIZING.md.

Something failed. What now?

Run npm run doctor. It lists what is missing. The common fixes are in docs/05-TROUBLESHOOTING-AND-CUSTOMIZING.md.
